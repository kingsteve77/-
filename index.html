📖 తెలుగు బైబిల్

పూర్తి తెలుగు బైబిల్ పాఠ్యం ఇంటర్నెట్ ద్వారా లోడ్ అవుతుంది. మొదటిసారి తెరవడానికి కొద్దిసేపు పట్టవచ్చు.

గ్రంథం మరియు అధ్యాయం ఎంచుకోండి. పూర్తి 66 గ్రంథాల తెలుగు వచన డేటా ఈ starter లో ఇంకా చేర్చబడలేదు; ప్రచురణకు అనుమతించిన పూర్తి అనువాదాన్ని జత చేయాలి.

డేటా మూలం పరిశీలన: 66 గ్రంథాల తెలుగు JSON ప్రాజెక్ట్. దాని లైసెన్స్, పూర్తి వచనాలు, అనువాద ఖచ్చితత్వం నిర్ధారించిన తర్వాతే పూర్తి పాఠ్యాన్ని బండిల్ చేయాలి.

⛪ చర్చి కుటుంబం

చర్చి అడ్మిన్: మీ చర్చిని సృష్టించండి

ఈ డెమోలో చర్చి వివరాలు ఈ పరికరంలో మాత్రమే సేవ్ అవుతాయి. నిజమైన బహుళ-యూజర్ యాప్‌కు సురక్షిత backend, admin role verification, cloud image storage అవసరం.

🔐 చర్చి అడ్మిన్

డెమో భద్రతా గమనిక: ఈ తెరలోని అడ్మిన్ పాత్ర పరికరంలో మాత్రమే ఉంటుంది. నిజమైన భద్రత కోసం సర్వర్‌లో ధృవీకరించిన admin login అవసరం.

సభ్యులను ఫోన్ నంబర్‌తో జోడించండి

🎥 మీటింగ్ నియంత్రణలు

మీటింగ్‌లో చేరి కెమెరా/మైక్ అనుమతులు ఇవ్వండి. ఈ నమూనాలో దిగువ నియంత్రణలు డెమో జాబితాపై పనిచేస్తాయి; ఇతరుల పరికరాలను నిజంగా mute/unmute చేయడానికి మీటింగ్ provider యొక్క authenticated moderator integration అవసరం.

🎥 ఆన్‌లైన్ ప్రార్థన సమావేశం

కెమెరా, మైక్రోఫోన్ అనుమతులు మీ బ్రౌజర్‌లో అడగబడవచ్చు. పాల్గొనేవారు గదిలో చేరిన తర్వాత host controls మీటింగ్ సర్వీస్‌పై ఆధారపడి ఉంటాయి.

ఈ embed పబ్లిక్ Jitsi సేవను ఉపయోగిస్తుంది. 200 మంది capacity లేదా admin moderation హామీ కాదు; production‌లో మీ స్వంత secure Jitsi deployment లేదా అనుకూల moderator service అవసరం.

🙏 ప్రార్థన అభ్యర్థనలు

గోప్యత: ఆరోగ్యం, ఫోన్ నంబర్లు లేదా ఇతర అత్యంత వ్యక్తిగత వివరాలు అవసరమైతే మాత్రమే పంచుకోండి. ఈ ప్రోటోటైప్ డేటా అదే బ్రౌజర్‌లో ఉంటుంది; ఇది ఇంకా సురక్షితమైన బహుళ-యూజర్ సర్వర్ కాదు.

చర్చి అభ్యర్థనలకు స్పందనలు ఇవ్వవచ్చు. నిజమైన ఇతర సభ్యులకు చూపడానికి backend అవసరం.

✉️ ఇన్‌బాక్స్

మీరు ఎంచుకున్న పాత్ర ఆధారంగా ప్రార్థన స్పందనలు, అడ్మిన్ సందేశాలు ఇక్కడ కనిపిస్తాయి. ఇది ప్రస్తుత పరికరంలోని డెమో ఇన్‌బాక్స్ మాత్రమే.

🗓️ చర్చి కార్యక్రమాలు

ఈ డెమోలో కార్యక్రమాలు స్థానికంగా సేవ్ అవుతాయి. ఉచిత Jitsi గది సృష్టించవచ్చు; 200 మంది సామర్థ్యం ఉచిత పబ్లిక్ సర్వీస్‌లో హామీ కాదు.

ఉచిత సేవ

ఈ starter లో ఎటువంటి చెల్లింపు లేదా subscription లేదు. హోస్టింగ్, cloud storage, push notifications మరియు 200-మంది live video కోసం ఉచిత సేవల పరిమితులు ఉంటాయి.

భద్రత: ఈ నమూనాలో అసలు login లేదా server-side admin verification లేదు. ప్రజలకు విడుదల చేసే ముందు తప్పనిసరిగా authentication, permissions, moderation మరియు privacy controls జోడించాలి.
